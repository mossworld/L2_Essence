<!--
================================================================================
  [멀티셀(Multisell) 설정 가이드라인]
================================================================================
  멀티셀은 플레이어가 특정 아이템을 지불하고 다른 아이템을 구매할 수 있는 "특별 상점"입니다.
  - 플레이어가 지불하는 아이템: "재료(ingredients)"
  - 플레이어가 보상으로 받는 아이템: "제품(products)"
  - 각 멀티셀 목록의 항목(entry)은 여러 개의 재료와 여러 개의 제품을 가질 수 있습니다.

================================================================================
  1. 파일 이름 및 호출 방식
================================================================================
  - 모든 멀티셀 파일은 숫자로 된 파일명(ID)을 가지며 확장자는 .xml이어야 합니다. (예: 123456.xml)
  - HTML에서 다음 링크(bypass)를 통해 멀티셀 목록을 표시할 수 있습니다:

    (1) 일반 방식 (전체 목록 표시):
        <a action="bypass -h npc_%objectId%_multisell 123456">
        - XML에 정의된 모든 항목을 있는 그대로 화면에 보여줍니다.

    (2) 교환 방식 (인벤토리 전용 표시):
        <a action="bypass -h npc_%objectId%_exc_multisell 123456">
        - 플레이어의 인벤토리 내 장비(착용하지 않은 무기/방어구)를 검색합니다.
        - 플레이어가 가지고 있는 장비를 "재료"로 요구하는 멀티셀 항목만 필터링하여 보여줍니다.

================================================================================
  2. <list> 속성 (Attributes)
================================================================================
  1) applyTaxes (세금 적용 여부)
     - 선택 사항 (기본값: "false")
     - "true"로 설정 시, 멀티셀에 포함된 모든 아데나(Adena, ID: 57) 소모량에 성 세금이 적용됩니다.
       (세금은 해당 영지를 소유한 성의 세율에 따라 징수됩니다.)
     - 고대 아데나(Ancient Adena)의 경우 5/6에 해당하는 금액에 대해 아데나로 세금이 부과됩니다.
       * 예시: 세율이 10%이고 고대 아데나 3,600개가 필요한 항목인 경우,
               실제 요구량은 [고대 아데나 3,600개] + [아데나 300개]가 됩니다.
               계산식: (10%) * (5/6) * (3600) = 300 아데나 추가 징수.

  2) maintainEnchantment (인챈트 상태 유지 여부)
     - 선택 사항 (기본값: "false")
     - 일반 방식(multisell)으로 열었을 때는 이 값이 "true"여도 무시되며 "false"로 작동합니다.
     - 교환 방식(exc_multisell)으로 열었을 때 "true"로 작동하며, 플레이어가 재료로 바친 
       무기나 방어구의 인챈트 수치가 완성된 제품에도 그대로 승계됩니다.
       * 예시: 소울 크리스탈(SA) 부여 멀티셀에서 플레이어가 "+3 크리스탈 스태프"를 재료로 바치면,
               인챈트가 유지되어 "+3 크리스탈 스태프 - 바디 블레스"를 받게 됩니다.

================================================================================
  3. XML 태그 구조
================================================================================
  - <list></list>                             : 멀티셀 목록의 시작과 끝을 선언합니다.
  - <item></item>                             : 목록 내의 단일 교환 항목(거래 공식)을 정의합니다.
  - <production id="아이템ID" count="수량"/>   : 획득할 제품을 추가합니다.
  - <ingredient id="아이템ID" count="수량"/>   : 소모할 재료를 추가합니다.
  - enchantmentLevel                          : 아이템의 인챈트(강화) 수치를 지정합니다.
================================================================================
-->

<list applyTaxes="true" maintainEnchantment="true">
	<!-- 첫 번째 거래 항목 예시: 재료 2가지(10번 아이템 1개, 200 아데나)로 제품 2가지(2번 1개, 3번 1개) 교환 -->
	<item>
		<production id="2" count="1"/>
		<production id="3" count="1"/>
		<ingredient id="10" count="1"/>
		<ingredient id="57" count="200"/>
	</item>
	
	<!-- 두 번째 거래 항목 예시: 10강 장비(1234번) 1개를 재료로 주면 4037번 아이템 10개를 획득 -->
	<item>
		<ingredient id="1234" enchantmentLevel="10" count="1"/>
		<production id="4037" count="10"/>
	</item>
	
	<!-- 세 번째 거래 항목 예시: 1억 아데나를 재료로 주면 10강 완성품 장비(5678번) 1개를 획득 -->
	<item>
		<ingredient id="57" count="100000000"/>
		<production id="5678" enchantmentLevel="10" count="1"/>
	</item>
</list>
